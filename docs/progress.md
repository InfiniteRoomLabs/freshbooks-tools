## Discoveries (Phase 4)

- 2026-09-02: pflag panics at cobra's flag-merge time on a same-shorthand, different-name collision between a persistent and a local flag; `api --query` therefore has no `-q` (the global `-q/--quiet` owns it).
- 2026-09-02: a cobra string flag registered with a non-empty default is indistinguishable from an explicitly set one, so a `flag > env > default` resolver never reaches the env twin. Register such flags with `""` and keep the default in the resolver (`--log-level` was the one offender; `--timeout` correctly uses `Changed()`).
- 2026-09-02: the Postman capture for `Projects/Delete Project` is sourced from the internal host and its own recorded response is a 404; the lib follows the docs (`DELETE /projects/business/{id}/project/{id}`), and the CLI's vendor-inventory cross-check allowlists that one command with that reasoning.
- 2026-09-02: `go list -m all` inside a workspace rewrites `go.work.sum`; read-only lanes must restore it (`git checkout -- go.work.sum`) or the QA lane's clean-tree check false-fails. `go.work.sum` is now tracked.
